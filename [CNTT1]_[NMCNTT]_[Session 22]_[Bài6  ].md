# 1. công thức Prompt 3 thành phần: Context – Expected – Actual- để nhờ AI giải thích lỗi này một cách bình dân nhất là :
**1. Context (Bối cảnh):**

Tôi đang sử dụng Windows 11, Git và Terminal trong VS Code để đẩy code lên GitHub.

**2. Expected (Kết quả mong muốn):**

Tôi muốn đẩy code từ máy tính lên repository GitHub thành công mà không gặp lỗi.

**3. Actual (Kết quả thực tế):**

Khi thực hiện lệnh Git, Terminal hiển thị thông báo lỗi:

`error: open(".git/FETCH_HEAD"): Permission denied`
